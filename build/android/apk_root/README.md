# Lightweight Web Engine (LWE) for Android
## How to build LWE for Android

### Prerequisite
```
export ANDROID_HOME=$HOME/Your/Android/Sdk
```

### Compile LWE
```
gradle build
```

## Note for Developers
The content of this directory shows the root of IM's gerrit root.
The directory structure is created by the ``release-android.sh``
